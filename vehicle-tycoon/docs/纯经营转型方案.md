# 纯经营转型方案

> 来源：2026-07-26 评审（`docs/reviews/2026-07-26-v1.3-中期评审.md`）后确认的转型方向。
> 本文件是 S0-S3 实施切片与验收标准的唯一权威来源。

## 核心定位

**通过采购、调度、维护和淘汰车辆，持续提高车队利润与运输能力。**

车辆快速换代不再是问题，而是核心玩法。玩家关心的不是"这辆车是谁"，而是"它还能不能赚钱、什么时候换最划算"。

## 系统取舍总表

| 旧系统 | 处理 | 新定位 |
|---|---|---|
| 车辆命名 | 删除 | 车型 + 编号自动生成 |
| 亲密度、清洗、抚摸 | 删除 | 避免无意义日常任务；保养保留改"检修"（只清磨损） |
| 性格特质 | 改造 | 出厂参数：节能、可靠、重载、高速（效果不变，语义换皮） |
| 车辆等级与经验 | 弱化 | 逐步改为里程、车龄（S2 落地） |
| 品质 | 重做 | 采购规格：经济型、标准型、工业型（S0 先换语义，S2 改采购时选定） |
| 专精 | 并入规格 | 快运、重载、耐用等运营配置（已拍板：不保留独立第三层） |
| 进化 | 删除 | 后续由"车型改装/技术换代"替代（S2 之后再说） |
| 荣誉殿堂 | 删除 | 改为经营报表和历史最佳车队（S2） |
| 拆解传承 | 重做 | 回收价值、零件返还、旧车残值（S2） |
| 声望 | 改为信誉 | 不可消费的企业指标：准时交付+、违约-；取消"花声望接贵重单"（S1） |
| 能源 | 改容量约束 | 功率上限模型，非体力条（已拍板，S3 落地） |
| 科技与工厂 | 保留并精简 | 服务产能、成本和运营策略；科技改经营路线互斥（S3） |
| 挑战、轮回 | 删除死代码 | 暂缓，S0 直接删 |

## 经营决策三问

1. **接什么单**：订单有距离、货量、时限、路线、违约条件；高价 ≠ 高利润（S1）
2. **派什么车**：不同车型有明确分工（小型灵活/卡车高本/火车集货/飞机救急/轮船长约），启用 parkingSpaces 产生车队组合取舍（S1/S2）
3. **什么时候换车**：资产生命周期曲线 = 采购价 - 累计运营成本 - 维修费 + 累计收入 + 当前残值（S2）

## 实施切片

| 切片 | 内容 | 遥测验收指标 |
|---|---|---|
| **S0 换皮**（✅ 已完成 2026-07-29） | 删命名/亲密度/进化/互动入口及相关成就教程；特质→出厂参数、品质→规格、专精→运营配置（机制不动）；删 Prestige/Challenge 死代码 | smoke/sim 全绿；玩家接触不到旧概念 |
| **S2 资产模型**（提前） | parkingSpaces 启用；里程/车龄；维修/翻新/出售/拆解；残值曲线；车队运营成本；经营报表 | 金币消耗率 4.8%→≥30%；内容点满后决策密度 ≥0.8 次/min |
| **S1 订单市场** | 距离/货量/时限/违约（违约只计在线时间）；目的地连单；紧急单；信誉不可消费 | autoAssign 不再是全局最优（smoke 反例） |
| **S3 能源容量 + 科技路线** | 能源改功率容量约束（超载降效）；科技改经营路线限选 1-2 条 | 储能顶格占比 71%→<30%；不同路线跑出不同车队结构 |

## 转型完成的判断标准

| 指标 | 基线（2026-07-26 遥测） | 目标 |
|---|---|---|
| 内容耗尽时刻 | 94.9 min | ≥ 4h 且耗尽后仍有运营决策 |
| 金币消耗率 | 4.8% | ≥ 30% |
| 100min 后决策密度 | 0.2 次/min | ≥ 1 次/min |
| 储能顶格占比 | 71% | < 30% |
| 解锁新车后的行为 | 无脑置换 | 打开报表算该留该换，无唯一答案 |

## 明确不做（转型期冻结）

配件、挑战、轮回、社交、音效；老存档不迁移（版本不匹配直接开新局）。
