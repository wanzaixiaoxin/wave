# Vehicle Tycoon 遥测报告（制作人视角）

> 模拟方式：真实游戏系统 + 虚拟时钟，1Hz 步进共 3 小时；贪心玩家策略（高价单优先、能研究就研究、新 tier 必买、闲钱升级）。
