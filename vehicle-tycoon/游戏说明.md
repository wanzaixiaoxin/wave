# 造物运输大亨 🚗 游戏说明

> **一句话**：造车 → 派单赚钱 → 检修维护 → 换代更高级的车 → 成为运输大亨

---

## 一、游戏目标

从一个只有 200 金币的小作坊起步，造出你的第一辆独轮车。通过**派它跑订单 → 赚金币和经验 → 升级规格/深化运营 → 解锁并置换更高级的车型**，最终造出星际飞船，成为横跨星际的运输大亨。

你扮演的不是"车主"，而是**运输企业的操盘手**：关心每辆车还能不能赚钱、什么时候置换最划算。

---

## 二、核心循环（游戏怎么运转）

游戏的核心是**一个永不停止的循环**，每一秒都在运转：

```
① 造车（车型名 + #编号自动命名）
   ↓
② 派车接订单 → 车跑出去（等几十秒，途中可能遇到路上事件）
   ↓
③ 订单完成 → 获得 🪙金币 + 📈经验 + 📈声望
   ↓
④ 金币用来：造更好的车 / 升级科技 / 扩建工厂 / 升级电站
   经验用来：给车升级 → 升级规格（经济型→标准型→工业型）
   ↓
⑤ 磨损累积 → 检修清零；车库满了 → 扩建 / 以旧换新 / 拆解
   ↓
⑥ 回到 ①（但这次造的是更高级的车，赚得更多）
```

**这个循环不需要你一直盯着看**——车跑订单的时候你可以去干别的，它会自动完成并到账。离线也会继续生产，上线时一次性领取。

## 三、各个模块的关系

```

              │  🏠 车库  │ ← 你所有的车都停在这里
              └─────┬────┘
                    │
       ┌────────────┼────────────┐
       ↓            ↓            ↓
   ┌──────┐   ┌────────┐   ┌────────┐
   │ 📮   │   │ 🔬    │   │ 🏭    │
   │ 订单  │   │ 科技树 │   │ 工厂   │
   └──┬───┘   └───┬────┘   └──┬─────┘
      │           │           │
      │  解锁新车 │           │ 产出零件
      │  提升效率 │           │ + 电站产电
      └─────┬─────┘           │
            ↓                 ↓
         ┌──────────────────────┐
         │    🪙 金币 + 📈 经验   │
         └──────────────────────┘
```

### 🏠 车库 —— 核心

你的所有车辆都停放在车库中。每辆车都是**一项运营资产**，有自己的：

- **等级**（1-10 级）：跑订单获得经验来升级，每级提升收入
- **采购规格**（⚪经济型→🔵标准型→🟡工业型）：规格越高，等级上限越高，收入倍率越高（工业型收入 ×2）
- **出厂参数**：出厂时随机获得一个被动增益——高速（订单耗时 -15%）、重载（收入 +20%）、精准（暴击率 +5%）、老练（经验 +20%）、节能（收入 +10%），以及🔥稀有的"幸运"（暴击 ×3）
- **运营配置**（标准型解锁，三选一，永久）：⚡快运（耗时 -25%，收入 -10%）、💪重载（收入 +25%，耗时 +15%）、🛡️耐用（磨损减半，经验 +15%）
- **磨损**（0-100）：每跑一单累积磨损，≥80 收入 -30%、耗时 +20%，花 2⚙️ **检修**清零

车库有**容量上限**（初始 6 格，可扩建到 12 格），满了就不能造新车。这时你需要做经营决策：扩建？以旧换新？还是拆解回收？

### 📮 订单 —— 赚金币的主要方式

有三种订单自动刷新：

| 订单类型 | 收益 | 要求 |
|----------|------|------|
| 📮 普通配送 | 基础价 × 等级加成 | 任意空闲车可接 |
| 🏔️ 长途运输 | ×2，经验更多 | 需要耐久度 ≥ 3 |
| 💎 贵重物品 | ×3 | 需要标准型以上 + 动用 10📈 客户关系 |

派车接单后，车会出去跑一段时间（30-60 秒），途中可能触发**路上事件**（修路、爆胎、交警、顺风车客……），2-3 选 1 的微决策影响本单耗时/收入/磨损。订单金额根据车的等级、规格、出厂参数动态计算，所以运营得好的车赚得更多。

连续派单会产生**疲劳**（连单越多收入越低，空闲 30 秒恢复），高磨损还有惩罚——派单节奏也是经营的一部分。

### 🔬 科技树 —— 解锁新车型

科技树是一条**单线**，共 5 级：

```
L1 基础机械 ─→ L2 内燃机 ─→ L3 自动化产线 ─→ L4 全球供应链 ─→ L5 星际物流
     │              │              │                │               │
  解锁规格系统   解锁小汽车/卡车  解锁火车/轮船    解锁飞机/火箭   解锁星际飞船
                                生产速度+25%     产线+1          全厂收入+50%
```

每级科技都有**前置条件**（比如需要生产一定数量的特定车型），满足后才能花费金币和零件来研究。

每级主线下面还挂着 **2 项子科技**（比如 L1 的「改良工具」「手工艺传承」、L5 的「曲率引擎」「深空网络」），每项可研究 **3 阶**，费用与耗时逐阶递增，效果逐阶叠加（建造耗时、每单耗电、声望获取、订单耗时、磨损、造价等）。主线之外还有 **4 项辅助科技**（物流优化/精益制造/技术档案/回收工艺），同样是 **3 阶制**的永久被动。子科技和辅助科技都与主线**共享一个研究槽**——先冲主线解锁车型，还是见缝插针深化数值，由你取舍。

科技只是车型解锁的一个维度。每档车型的解锁条件是**逐车型声明、随时代而不同**的（造车下拉里未解锁的车型会列出全部缺失条件和进度）：

- **手工作坊时代（T2/T3）**：靠**产量**——造 3 辆独轮车解锁自行车，造 3 辆自行车解锁马车，手艺是干出来的；
- **工业时代（T4-T7）**：靠**科技 + 工厂等级**——产线设备决定能造什么（如卡车需工厂 Lv.3、轮船需工厂 Lv.5）；
- **电气/航天时代（T8-T10）**：靠**科技 + 电站等级**——飞机要电站 Lv.4，星际飞船要电站 Lv.8，能源与精密制造是瓶颈；
- **品牌声望**自内燃机时代（T4）起贯穿始终——高端车型需要口碑背书（100 📈 起，星际飞船要 6000 📈），多跑订单攒口碑。

### 🏭 工厂 —— 零件工厂 + 电站

工厂**持续生产零件 ⚙️**（不是造车！），零件是造车和升级规格的必备材料。升级工厂可以增加产线数量、提升产出速率，车库里的最高车型还会给工厂带来进度加成；工厂升到 Lv.5 时建造队列还会 +1 个排队位。急需零件时可以开「超负荷运转」，60 秒产出翻倍（耗 50⚡，之后冷却 5 分钟）。

等级之外，工厂和电站还有**改造线**（即时购买生效，不占研究槽）：工厂的产线自动化（零件速率 +15%/级）、精益生产（造车金币 -6%/级）、装配工艺（建造耗时 -6%/级），电站的能效优化（产出 +12%/级）、储能扩容（上限 +25%/级），每条 5 级，是金币和零件的长期投入口。

工厂面板里还有企业的**动力源——电站**。电站名字随科技时代演进（燃煤锅炉→燃油电站→并网电站→清洁能源→聚变堆），持续产出能源 ⚡，储存上限随等级提升。造车、升级规格、派车跑单都要用电；能源跟不上时订单会陷入「动力不足」（耗时 +50%），记得及时升级电站。

### 🏆 成就 —— 里程碑

完成特定目标解锁成就，获得金币/零件奖励和称号。成就涵盖造车数量、累计收入、以旧换新、经验传承、科技与工厂深度等经营维度。

## 四、一辆车的完整生命周期

```
造车 → 落地自动命名（车型名 + #编号），随机获得一个出厂参数
  ↓
派它跑订单 → 获得经验 + 金币 + 声望
  ↓
经验够了 → 升级 → 收入提升
  ↓
攒够金币和零件 → 升级规格（经济型→标准型→工业型，耗时进场，期间锁车）
  ↓
属性升级 → 点速度/载货/耐久（每级消耗递增）
  ↓
标准型以上 → 选运营配置（快运/重载/耐用，永久）
  ↓
磨损累积 → 检修清零（2⚙️，有冷却）
  ↓
车型落后了 → 以旧换新（补差价置换更高 tier）或拆解回收
  ↓
拆解的经验进入传承池 → 下一辆新车落地继承，起步就是高等级
```

车队快速换代不是损失，而是核心玩法：旧车回收零件与金币，经验传承给新车，运力不断升级。

## 六、小技巧

1. **前期优先把一辆车升到工业型规格**——工业型收入是经济型的 2 倍，更快积累第一桶金
2. **别把所有车都留着**——车库满了就得做选择。以旧换新能补差价一步换代，拆解能回收零件并把经验传给下一辆新车
3. **规格比等级重要**——经济型车升到满级也不如标准型 Lv.8 赚得多
4. **零件要省着用**——前期零件紧缺，优先给主力车升规格，检修别断
5. **离线也会赚钱**——产线一直在生产，上线时一次性领取。放心关掉游戏
